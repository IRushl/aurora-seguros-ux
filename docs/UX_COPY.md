# UX Writing · contrato vigente v3

Español claro y cercano, con acciones específicas. «Personas» para pedir cantidad/edades; «plan» para opciones y selección. No se presenta el ejemplo como una contratación. Nombres, importes y prestaciones del catálogo se conservan como simulación documentada.

| Ubicación | Texto vigente | Propósito |
| --- | --- | --- |
| S01 título | Cotiza tu Seguro Salud Flex | Mantener el objetivo y CTA del brief |
| S01 descripción | Conoce las opciones de Salud Flex, elige a quiénes quieres incluir y compara servicios antes de seleccionar un plan. | Explicar qué se explora |
| S01 pasos | Ingresa tus datos → Indica a quiénes quieres incluir → Compara y elige tu plan | Orientar sin términos técnicos |
| S01 formulario | Comencemos con tus datos / Cotizar | Facilitar el inicio en los tres formatos |
| S01 propósito | Tu nombre identifica este recorrido. El correo y el celular completan los datos de contacto del ejercicio; solo se guardan en esta pestaña. | Explicar el uso real de la información |
| S02 | ¿A quiénes quieres incluir? | Hablar de personas en lugar de configurar un formulario |
| S02 descripción | Indica cuántas personas quieres tener en cuenta y la edad de cada una. Así podremos mostrarte las opciones para tu grupo. | Instrucción y consecuencia |
| S02 CTA | Ver planes disponibles | Anticipar el siguiente resultado |
| S03 título | Encuentra el plan que prefieras | Invitar a comparar sin recomendar sin evidencia |
| S03 detalle | Ver detalles del plan | Profundizar dentro de la tarjeta |
| S03 selección | Plan seleccionado / Ver resumen de mi elección | Confirmar el estado y la siguiente acción |
| S03 aclaración | Planes y precios de ejemplo: no son una oferta comercial. | Una advertencia contextual |
| D01 | Tu selección está lista | Confirmar una elección, no una compra |
| D01 aclaración | Esta elección es de ejemplo y no te compromete a contratar. No has comprado un seguro ni se ha emitido una póliza. | Cierre veraz |
| D01 acciones | Volver a comparar / Comenzar de nuevo | Diferenciar conservar y borrar |

Los límites de demostración siguen explícitos: 1–20 personas y 0–130 años, sin atribuirlos a elegibilidad. Los detalles explican límites por persona, acumulación y ejemplos de exclusión. «Copagos» se aclara como lo que pagarías por atención; se usa «periodos de espera» en lugar de carencias. El ejercicio no simula esas condiciones.

La corrección de formatos no verifica identidad, correo o titularidad del celular. Los mensajes de éxito confirman únicamente una acción local. Los estados conservan resumen de errores, enlaces a campos, reintento y valores. La decisión de copy sigue pendiente de evaluación con personas; la suite técnica comprueba correspondencia y comportamiento, no comprensión poblacional.

## Ajustes finales aceptados

| Estado | Título / acción |
| --- | --- |
| Vacío S03 | No hay planes disponibles para mostrar. La consulta terminó sin resultados. Revisar personas / Actualizar opciones |
| Fallo S03 | No pudimos cargar los planes. Ocurrió un problema de carga; datos conservados. Reintentar carga / Revisar personas |
| Detalle abierto | Ocultar detalles del plan |
| Contacto S02 | Revisar o editar mis datos → Ocultar datos de contacto / Editar datos en Inicio |

El vacío es informativo y el fallo requiere recuperación. No se atribuye ausencia de resultados a elegibilidad de las personas.
